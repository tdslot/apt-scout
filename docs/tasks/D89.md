# D89

State: READY; v1 security work, independent of the TUI. The ledger holds the same state; this file holds the brief.

Escape what a root run prints. B7 in `docs/threat-model.md` requires it and records that nothing does it today: a
mirror's URL, `Origin`, `Label` or error text can carry `ESC`, and printing it as root into a shared terminal is a
control-sequence injection into the user's terminal.

The four paths that reach a terminal today, cited from the record: the report (`src/main.rs:771`–`773`), the closing
line of a write, which interpolates the selected URI (`:2547`), a rejected entry echoed in a note (`rejected_note` at
`:3283`, printed at `:3313`), and error or warning text that can carry a URL (`:2265`, `:3490`).

Acceptance:
- one unit test per path, each feeding a string that contains `ESC` and asserting the printed line carries no control
  character;
- one container case that builds a rejected entry from a URL containing an escape and greps the run's output for the raw
  byte, so the check is end to end and not only a unit test;
- the PR states the mutation each test survives, per `TEST-1`, or why no such mutation exists;
- no new dependency: the escape table is a small map of the control ranges the tool must replace.

Not claimed: that every byte a mirror can send is escaped — this covers what reaches a terminal on those four paths.
