# D91

State: READY; coverage, not a defect. The ledger holds the same state; this file holds the brief.

D89 escaped every print site that carries text the run did not author, and fourteen tests pin part of that. No test
pins the escape in `sources_section`, the geolocation note, the fallback list warning or `main`'s `error:` line:
deleting the `control_free` call at any of them leaves the suite green, which is the state `TEST-1` exists to prevent.

Acceptance:
- one test per unpinned site, each feeding a string with a control character and asserting the printed line carries
  none;
- each test shown to fail with the escape removed, and the mutation named in the PR;
- a script or a test that lists the `control_free` call sites in `src/main.rs` and fails when one has no test naming
  it, so the next site added is covered rather than counted.

Not claimed: that every `control_free` call needs its own test — a site whose input is a compile-time constant (the
section title's `root`, the plan's `relative`) cannot carry one, and the brief's script says which sites are exempt
and why.
