### D31

- [ ] **D31 — the translations, in ordered groups.** One group is one PR. Every group depends on D30c, because a catalog translated before the mechanism covers the whole tree would be missing the ids the write path adds and would be re-opened by the next mechanism entry; no group starts early. Groups are taken in the order below, and each adds one `locales/<tag>/main.ftl` plus its tag to the shipped set the tests require in `src/l10n.rs`, so two groups cannot share a worktree and no group can merge without the full CI matrix. **A group closes only when both catalog gates pass for its catalogs** — every English id present, with the missing ids listed on failure, and every message's placeholder set equal to the English one — and **only when the human has accepted each of its catalogs and the PR names who read it.** A catalog nobody can read is not shipped: English is correct and a wrong translation is not, which is the one gate no test can carry. The translator's work queue is the gate itself: create `locales/<tag>/main.ftl` holding only its header comment, run `cargo test --locked` and use the missing-id list it prints as the file to fill. The ordered list, and why it is that order:

1. **Lithuanian (`lt`), D31a, first** — the operator's language and the reason this work exists, and the first catalog to exercise a plural rule with more than two categories (`one`/`few`/`other` for Lithuanian integers, of which the catalog must carry all three), so the machinery is proved on the smallest real case.
2. **Baltic remainder (`lv`, `et`), D31b** — the operator's two neighbours and the other Baltic states; small catalogs that finish the group Lithuanian opens.
3. **Nordic, EU official (`sv`, `da`, `fi`), D31c** — Swedish, Danish and Finnish are EU official languages as well as Nordic ones: the group is Nordic by name and EU by right, and the Nordic request names its three EU members first.
4. **Nordic extension, not EU (`nb`, `is`), D31d** — Norwegian Bokmål and Icelandic. **They are not EU official languages.** They ship because the request named the Nordic set, and this entry says so that nobody later "corrects" the list by deleting them.
5. **Western EU (`de`, `fr`, `nl`), D31e** — the largest Western European speaker bases.
6. **Southern EU (`it`, `es`, `pt`), D31f** — the largest Southern European speaker bases.
7. **Non-Latin EU (`el`, `bg`), D31g** — Greek and Bulgarian, the first shipped catalogs in a script that is not Latin, so encoding and column width are proved on single-width non-Latin text before Chinese adds double-width.
8. **Central/Eastern EU (`pl`, `cs`, `sk`), D31h** — the largest Central European speaker bases.
9. **Central/Eastern EU, continued (`hu`, `ro`, `hr`), D31i.**
10. **Remainder and closure (`sl`), D31j** — Slovenian last, plus the check that every locale in this list has a catalog, that the list has no duplicate tag, and that the missing-id, comment and placeholder gates run over all of them.

Deferred explicitly, not dropped: Maltese (`mt`) and Irish (`ga`) are EU official languages but the two smallest catalogs in the set; Norwegian Nynorsk (`nn`) is not shipped and is never served by Bokmål; Traditional Chinese (`zh-Hant`) is D32's deferral; every language outside this list prints English under docs/spec/localization.md. Selecting a deferred locale is never an error and never a substitution — it prints English. [SPEC: docs/spec/localization.md]
